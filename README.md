# Библиотека кампуса

Учебное мобильное приложение для бронирования книг в библиотеке кампуса: студент ищет книгу,
бронирует её на 48 часов и забирает по QR-коду, модератор выдаёт книги, сверяет полки и ведёт каталог.
Дизайн перенесён из `design/` один в один.

- Expo SDK 57, React Native 0.86, TypeScript (strict)
- Навигация — expo-router (файлы в `app/`)
- Данные — локальная SQLite на устройстве (`expo-sqlite`), без сервера
- Все компоненты свои, без UI-китов; работает в **Expo Go**

## Запуск

Нужны Node.js 20+ и приложение Expo Go на телефоне.

```bash
npm install
```

```bash
npx expo start
```

Отсканируйте QR-код из терминала камерой (iOS) или в Expo Go (Android).

При первом запуске база заполняется тестовыми данными (`src/mocks/seed.ts`): 11 книг,
10 студентов, модератор, брони во всех статусах. Сроки считаются от текущего дня.

### Меню отладки

В dev-сборке долгое нажатие на бейдж «Библиотека кампуса» в шапке открывает `/dev`:

- быстрый вход студентом или модератором;
- переключатели состояний, которые в локальной базе сами не возникают: «Нет подключения»,
  «Книгу только что забронировали», ошибка брони, «Сессия истекла», ошибка загрузки;
- демо всех компонентов дизайн-системы;
- сброс базы к тестовым данным.

### Web-превью (необязательно)

```bash
npx expo start --web
```

Нужно только для быстрой проверки вёрстки в браузере. На web база работает в памяти через
`sql.js` (`src/db/client.web.ts`), градиенты и камера не поддерживаются. Целевые платформы — iOS и Android.

  profile-edit.tsx      редактирование профиля

  theme/tokens.ts       все дизайн-токены: цвета, шрифты, отступы, радиусы, тени, градиенты

## Где что лежит

- **Правила брони** (48 часов, лимит 3 брони, 14 дней на руках, 24 часа на автобронь из очереди,
  время закрытия) — таблица `settings`, значения задаются в `src/mocks/seed.ts`.
- **Статусы и переходы** — `src/db/bookings.ts`: просрочка и истечение брони пересчитываются
  при каждом чтении (`refreshStatuses`); освободившийся экземпляр уходит первому в очереди.
- **Модераторские операции** — `src/db/moderator.ts`: журнал, поиск брони для выдачи, сверка.
- **Импорт каталога** — `src/db/catalogImport.ts` (проверка строк и запись одной транзакцией)
  и `src/lib/files.ts` (чтение CSV/XLSX, выгрузка CSV).
- **Новые миграции** добавляются в конец массива `MIGRATIONS` в `src/db/schema.ts`.

## Ограничения

- Сервера нет: письма и сообщения в Telegram не отправляются, тексты подтверждений показываются как есть.
- Пароли хранятся локально как SHA-256 с солью (`expo-crypto`); сброс пароля только показывает экран подтверждения.
- Разделы модератора свёрстаны по макетам 1440×900 и на телефоне открываются в альбомной ориентации.

Все отличия от макета и принятые решения — в `docs/decisions.md`.
