# Спецификация — «Библиотека кампуса»

Источник: `design/screens/*.html` (7 бандлов: «Бронирование книг — библиотека кампуса», «Брони», «Вход»,
«Выдача», «Журнал», «Каталог», «Состояния»), `design/previews/*.pdf` (визуальная сверка),
`design/system/campus-library-design-system.html`.

Тексты, состояния и значения в спецификации сверены с HTML: каждый экран в HTML — компонент с
перечислимым свойством `state`, имена состояний указаны в таблицах как `state=…`.

Дизайн-система прямо говорит: «Мобильный веб для студентов и десктоп для модератора».
Студенческие экраны — 390×844 (телефон, портрет), модераторские — 1440×900 (ноутбук, альбом;
в PDF они уменьшены до 1080×675).

---

## 1. Роли

| Роль | Как попадает | Что видит |
|---|---|---|
| Гость | Запуск без входа | Поиск, карточка книги. «Мои брони» → приглашение войти; «Профиль» → экран входа |
| Студент | Вход / регистрация | Поиск, брони, профиль |
| Модератор | Тот же экран входа («Модераторы входят здесь же — после входа откроется журнал») | Журнал, Выдача и сверка, Каталог |

## 3. Навигация

```
Корень
├─ (student) — нижний TabBar: Поиск · Мои брони · Профиль
│   ├─ Поиск (stack): S1 Главная → S2 Результаты → S4 Книга → S5 Бронь оформлена
│   ├─ Мои брони (stack): S8 → S9 Бронь → S4 Книга
│   └─ Профиль (stack): S10 → S11 Редактирование
├─ S3 Меню — модальная панель справа, открывается из шапки S1/S2/S8/S10
├─ (auth) — модальный стек с «×»: S6 Вход/Регистрация → S7 Сброс пароля
└─ (moderator) — верхние вкладки: M1 Журнал · M2 Выдача и сверка · M3 Каталог
    └─ Каталог (stack): M3 → M4 Импорт; M5 Новая/Правка — модально
```

### Правила (из текстов макетов)
- Бронь держится 48 ч; если не забрали — `expired`, книга снова в наличии; первый в очереди получает автобронь.
- Не больше 3 активных броней.
- Срок выдачи — 14 дней по умолчанию, модератор может изменить дату.
- «Я вернул книгу» → `awaiting_check`, книга сразу доступна в каталоге; модератор при обходе: «На полке — закрыть» → `closed`, «Нет на полке» → `overdue` + книга пропадает из наличия.
- Просрочка: `issued` и `due_at` прошёл → `overdue` (системой, в 00:00).
- Библиотека закрыта в сб и вс — срок забора, выпадающий на выходные, предупреждается.
